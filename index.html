The schema behind the numbers

modeled

You have real Salesforce and Snowflake access to check this against; I don't. So instead of guessing at your actual data, here's the schema I'd propose to produce every number in the funnel and rep sections above, plus two queries that, run against it, generate those exact figures. This is a design proposal, not a live connection.

Salesforce object/field schema + the queries behind the charts above
Opportunity (standard object, extended) ‚îú‚îÄ StageName picklist Prospecting ¬∑ Qualified ¬∑ Demo ¬∑ Proposal ¬∑ Negotiation ¬∑ Closed Won ¬∑ Closed Lost ‚îÇ (the funnel above only tracks the won path; Closed Lost still lives in the picklist) ‚îú‚îÄ Segment__c picklist SMB ¬∑ Enterprise (formula field off Account employee count / deal size) ‚îú‚îÄ OwnerId lookup User (GTM rep through Qualified, reassigned to an AE by Flow on entry to Demo) ‚îú‚îÄ Demo_Scheduled_Date__c date required to enter Demo ‚îú‚îÄ Proposal_Sent_Date__c date required to enter Proposal ‚îú‚îÄ Decision_Maker_Contact__c lookup Contact (required to enter Negotiation) ‚îú‚îÄ Amount currency required to enter Proposal ‚îî‚îÄ CloseDate date required to enter Closed Won / Closed Lost Account (standard object, extended) ‚îî‚îÄ Payroll_Processing_Volume__c currency, rollup (written nightly from Snowflake, not sales-entered) int_pipeline_stages (Snowflake, built from the synced Opportunity object) one row per opportunity per stage it has passed through, with segment and stage_order. This is what the funnel and rep-performance sections above are actually queried from.

SMB vs. Enterprise, Closed Won

select segment, count(*) as closed_won from int_pipeline_stages where stage = 'Closed Won' and close_date >= date_trunc('quarter', current_date) group by segment
‚Üí SMB 23, Enterprise 18, the exact split in the funnel chart above.

Qualified ‚Üí Demo conversion

select count(*) filter (where stage_order >= 3) * 1.0 / count(*) filter (where stage_order >= 2) as rate from int_pipeline_stages
‚Üí 210 / 340 = 62%, the same rate chained into the hiring-plan calculator above.
